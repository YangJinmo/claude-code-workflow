## 왜 이렇게 구성했는가
반복적인 컨텍스트 손실, 임시방편적 코드 수정, 불필요한 verbose 출력
같은 문제를 겪은 뒤, 작업을 태스크 단위로 쪼개고 검증 가능한 방식으로
진행하는 것을 우선했습니다. 위 항목들은 실제 세션 로그에 남은 사용
이력을 기준으로 정리한 것이며, 설정만 해두고 실행 기록이 없는 기능
(예: 일부 MCP 서버, 특정 리서치/분석 스킬)은 포함하지 않았습니다.
